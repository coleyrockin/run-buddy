# Run Buddy

Responsive fitness landing page built with semantic HTML5 and modern CSS — featuring Flexbox layouts, CSS Grid, and mobile-first design.

## About

Run Buddy is a multi-section marketing landing page for a fictional fitness company. It showcases responsive web design fundamentals — media queries, Flexbox for component layout, CSS Grid for page structure, and semantic HTML for accessibility. No JavaScript, no frameworks, just clean HTML and CSS.

## Features

- Fully responsive layout from mobile to desktop
- Hero banner with call-to-action
- Trainer profile cards with images
- Service and pricing sections
- Contact form with styled inputs
- Sticky navigation header
- CSS custom properties for theming
- Semantic HTML5 landmarks

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 (semantic) |
| Layout | CSS Flexbox, CSS Grid |
| Responsive | Media queries, mobile-first |
| Methodology | BEM-inspired class naming |

Open `index.html` in your browser.
